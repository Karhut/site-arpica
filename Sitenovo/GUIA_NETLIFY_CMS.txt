                    PASSO 1: PREPARAR REPOSITÓRIO GITHUB
================================================================================

**O que é GitHub?**
GitHub é um serviço online para guardar código e colaborar.
Netlify CMS precisa de GitHub para funcionar.

**PASSO 1.1: Criar Conta GitHub** (Se não tiver)
1. Ir para https://github.com/signup
2. Criar conta com email
3. Confirmar email
4. Criar novo repositório:
   - Nome: site-arpica
   - Descrição: Website da ARPICA
   - Público (ou Privado - à sua escolha)
   - Adicionar README.md
   - Criar repositório

**PASSO 1.2: Fazer Upload do Código**
1. Ter instalado Git no computador:
   - Windows: https://git-scm.com/download/win (instalar)
   - Mac: https://git-scm.com/download/mac
   - Linux: sudo apt install git

2. Abrir PowerShell/Terminal na pasta Sitenovo:
   ```
   cd "C:\Users\Karhut\Documents\Site ARPICA\Sitenovo"
   ```

3. Inicializar Git:
   ```
   git init
   git add .
   git commit -m "ARPICA site v1.0 - Ready for Netlify"
   git branch -M main
   ```

4. Ligar ao repositório GitHub:
   ```
   git remote add origin https://github.com/[SEU_USERNAME]/site-arpica.git
   git push -u origin main
   ```
   (Vai pedir username e password/token do GitHub)

                      PASSO 2: CONFIGURAR NETLIFY
================================================================================

**PASSO 2.1: Criar Conta Netlify**
1. Ir para https://netlify.com
2. Clicar "Sign up" 
3. Escolher "Sign up with GitHub"
4. Autorizar Netlify a aceder ao GitHub
5. Confirmar email

**PASSO 2.2: Deploy do Site**
1. Na dashboard Netlify, clicar "Add new site" → "Import an existing project"
2. Conectar GitHub
3. Autorizar Netlify
4. Selecionar repositório "site-arpica"
5. Branch: main
6. Build command: (deixar vazio - é site estático)
7. Publish directory: . (apenas ponto)
8. Deploy!

✓ Site estará live em: https://[seu-nome].netlify.app

================================================================================
                   PASSO 3: HABILITAR NETLIFY CMS
================================================================================

**PASSO 3.1: Configurar Netlify Identity**
1. Na dashboard Netlify → Site settings
2. Build & deploy → Authentication
3. Habilitar "Git Gateway"
4. Aceitar e ativar

**PASSO 3.2: Configurar Autorização**
1. Ir para: Administração → Utilizadores (ou "Users" em inglês)
2. Convites → Enviar convite
3. Email do admin da ARPICA
4. Definir papel: "Admin"
5. Copiar link de convite
6. Utilizador clica no link e define password

**PASSO 3.3: Aceder ao CMS**
- Ir para: https://[seu-site].netlify.app/admin/
- Fazer login com email/password
- Será apresentado painel visual! 🎉

================================================================================
                       PASSO 4: USAR O CMS
================================================================================

**FUNCIONALIDADES DISPONÍVEIS:**

1. **Atividades** - Editar/criar atividades
   - Ir a Collections → Atividades
   - Nova atividade
   - Preencher campos
   - Publicar (ou deixar como Draft)

2. **Membros da Direção** - Adicionar/editar pessoas
   - Collections → Membros da Direção
   - Novo membro
   - Preencher nome, cargo, secção
   - Publicar

3. **Documentos** - Adicionar links de documentos
   - Collections → Documentos
   - Novo documento
   - Ano, tipo, URL do PDF
   - Publicar

4. **Notícias** - Criar notícias/eventos (NOVO!)
   - Collections → Notícias & Eventos
   - Nova notícia
   - Título, data, conteúdo, imagem
   - Publicar

5. **Configurações** - Editar contactos, horários, etc
   - Config → Informações da ARPICA
   - Editar dados
   - Salvar

================================================================================
                    PASSO 7: PROBLEMAS COMUNS
================================================================================

**"Erro: Git Gateway não está habilitado"**
→ Ir a: Site settings → Build & deploy → Authentication → Habilitar Git Gateway

**"Erro de autenticação no CMS"**
→ Limpar cookies do navegador
→ Fazer logout completo
→ Fazer login novamente

**"Ficheiros não aparecem no CMS"**
→ Estrutura de pastas deve ser: _data/[collection]/
→ Ficheiros devem ser .json ou .md

**"Site não atualiza após publicar"**
→ Pode levar 30-60 segundos
→ Fazer refresh da página (Ctrl+F5)
→ Verificar Netlify deploy logs
