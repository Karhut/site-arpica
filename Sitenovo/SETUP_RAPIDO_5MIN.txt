================================================================================
                         PROBLEMAS?
================================================================================

❌ "Netlify Drop não funciona"
→ Usar opção GitHub em vez disso

❌ "CMS mostra apenas interface vazia"
→ Ir a Site settings → Identity → Git Gateway → Verificar se está ativo

❌ "Erro ao fazer login no CMS"
→ Limpar cookies do navegador
→ Tentar incógnito (Ctrl+Shift+N)

❌ "Ficheiros não aparecem no GitHub"
→ Fazer refresh (F5) no navegador
→ Tentar fazer upload novamente

Qualquer dúvida, avisa! 💬
