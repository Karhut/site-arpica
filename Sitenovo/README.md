## 🚀 COMO USAR

### 1. EDITAR CONTEÚDO (AGORA!)

Abra cada ficheiro HTML e procure por `[MUDAR: ...]`:

```html
<!-- Exemplo: -->
<h1>[MUDAR: Título da página]</h1>
<!-- Mudar para: -->
<h1>Bem-vindo à ARPICA</h1>
```

### 2. FICHEIROS PARA EDITAR (POR ORDEM DE PRIORIDADE)

1. **index.html** - Homepage principal ✅ (com hero bonito)
2. **sobre.html** - Informação sobre ARPICA
3. **actividades.html** - Programas e serviços
4. **direcao.html** - Direção e Conselho ✅ (NOVO!)
5. **voluntariado.html** - Oportunidades de voluntariado
6. **contacto.html** - Formulário de contacto
7. **galeria.html** - Fotos dos eventos ✅ (Grid responsivo)
8. **documentos.html** - Contas e relatórios

### 3. ADICIONAR IMAGENS

Coloque todas as imagens em: `images/`

As imagens precisam de estar em:
- `images/logo.svg` - Logo ARPICA
- `images/gallery/` - Fotos da galeria
- `images/team/` - Fotos da equipa

### 4. TESTAR NO NAVEGADOR

1. Abra `index.html` no navegador (duplo-clique)
2. Clique nos links de navegação
3. Verifique se todos os links funcionam
4. Teste em mobile também (redimensione a janela)
5. Verifique o menu em diferentes tamanhos de janela
